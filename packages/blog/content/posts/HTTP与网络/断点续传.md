# 断点续传

## 断点下载

客户端可以先发送 HEAD 请求，通过响应头中的 `Accept-Ranges: bytes` 和 `Content-Length` 判断服务器是否支持按字节范围下载。支持时，客户端使用 `Range` 请求头分段请求，例如先请求 `bytes=0-512`，再请求 `bytes=513-1024`，分别保存临时文件后组装成完整文件。

原笔记指出，浏览器页面无法直接完成这类桌面应用式的本地文件拼装。

## 断点上传

用户选择文件后，前端把文件切分为多个分片，计算完整文件及各分片的 MD5。原笔记到此为止，没有记录服务端校验、合并或重试流程，因此本整理不补充这些步骤。
