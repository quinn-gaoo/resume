# Nginx 负载均衡

## 轮询

轮询是默认策略，请求按时间顺序分配给不同的后端服务器，宕机节点会被自动剔除。

## weight

`weight` 为各服务器设置轮询权重，访问比例与权重成正比，适合后端服务器性能不一致的情况。

## ip_hash

`ip_hash` 根据客户端 IP 的 Hash 结果定位服务器，使同一客户端后续请求继续到达同一服务器。

## fair

`fair` 按后端服务器响应时间分配请求，响应时间短的优先。原笔记将其作为一种负载均衡策略记录。

## url_hash

`url_hash` 根据请求 URL 的 Hash 结果分配服务器，使同一 URL 定向到同一后端。后端服务器承担缓存时，这种方式更有效。
